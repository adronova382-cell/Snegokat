# ❄️ Снегокат: гаражный тюнинг

Браузерная игра про снегокат: катайся с горки, крути сальто, строй трамплины лопатой,
паяй электронику и собери мотор из старой бензопилы.

## Как запустить
- **На телефоне (и вообще проще всего):** скачай один файл `snegokat.html` и открой его в браузере. Всё внутри.
- На компьютере можно открыть `index.html` из скачанной целиком папки.

`snegokat.html` собирается из исходников командой `python3 build.py`.

## Что есть
- **Горка** — физика, прыжки, сальто (бэк/фронт, двойные, тройные), трюки Супермен / Без рук / Канкан / Шпагат, комбо-множитель, падения.
- **Стройка лопатой** — насыпать / копать / сгладить, кикеры, приземлялки, заливка льдом (с ведром). Снег ограничен.
- **Пайка** — соединяешь выводы проводами и паяешь каждую точку (холодная пайка / перегрев).
  Перепутал полярность — не горит, забыл резистор — светодиод сгорел, замкнул + и − — аккумулятор сгорел.
  Схемы: фара, клаксон, стоп-сигнал, подсветка, поворотники (тактовые кнопки), сигнализация, спидометр (с прошивкой), колонка.
- **Мотор из бензопилы** — 9 этапов: купить пилу, открутить закисшие болты, отмыть карбюратор,
  поставить свечу и мембраны, выточить звёздочку, сварить раму, натянуть цепь, завести с подсоса, отрегулировать карб.
  Потом снегокат едет сам — нужна топливная смесь 1:50 (неправильная смесь убивает мотор).
- **Ночь** — без фары темно, с фарой ×1.5 монет. Сигналка защищает гараж от воришек.
- **Магазин, барахолка, улучшения, достижения, статистика.**
- **Сохранение** — автоматически в localStorage (после действий, каждые 5 с и при закрытии), плюс экспорт/импорт кодом.

## Управление
| Клавиша | Действие |
|---|---|
| Пробел | оттолкнуться |
| ← → / A D | вращение в воздухе |
| Z X C V | трюки (держать в воздухе, отпустить до приземления) |
| ↑ / W | газ (с мотором) |
| ↓ / S | тормоз |
| Q E H L | поворотники, клаксон, фара |
| B N R | стройка, ночь, заново |
